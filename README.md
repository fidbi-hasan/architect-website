# BR Architects Website

A minimalist architectural portfolio designed following the **xAI design language** (`DESIGN.md`).

## Design Implementation Highlights
- **Canvas**: Pure near-black canvas (`#0a0a0a`) edge-to-edge.
- **Typography**: Inter (weight 400 with negative tracking at display scale) paired with Geist Mono (uppercase with positive tracking for technical eyebrows and metric counters).
- **Interactive Vocabulary**: Strict white-outline pill system (`rounded.pill` 9999px) with translucent-white borders (`rgba(255, 255, 255, 0.25)`).
- **Cards & Surfaces**: Level-1 hairline borders (`#212327`) on `#191919` (`canvas-card`) with 8px radius (`rounded.sm`), with zero artificial drop-shadows.
- **Responsive**: Fully responsive layout across mobile (<768px), tablet, and desktop viewports.
